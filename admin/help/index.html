GitHub 토큰(PAT) 발급 방법

관리자 페이지는 게시할 때 이 토큰을 이용해 GitHub 저장소에 직접 저장합니다. 아래 순서대로 한 번만 발급받아 두면, 이후에는 로그인 화면에서 바로 사용할 수 있습니다.

1
github.com에 로그인합니다

웹 브라우저에서 github.com 으로 접속한 뒤, 백업 저장소를 관리하는 계정으로 로그인합니다.

2
토큰 발급 메뉴로 이동합니다

오른쪽 위 프로필 사진 클릭 → Settings → 왼쪽 메뉴 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens 로 들어갑니다.

직접 이동하려면 주소창에 github.com/settings/tokens?type=beta 를 입력해도 됩니다.

3
새 토큰을 생성합니다

Generate new token 버튼을 누른 뒤, 아래 값으로 설정합니다.

  • Token name: minddent-admin
  • Expiration(만료 기한): 가능한 가장 긴 기간(예: 1년, No expiration이 있다면 선택 가능)
  • Repository access: Only select repositories 선택 후, 이 백업 사이트가 있는 저장소를 목록에서 선택
  • Permissions → Repository permissions에서 Contents 항목을 찾아 Read and write 로 설정

다른 권한 항목은 건드리지 않아도 됩니다. 맨 아래 Generate token 버튼을 누릅니다.

4
생성된 토큰을 복사해 관리자 페이지에 붙여넣습니다

토큰은 github_pat_... 형태의 긴 문자열로 한 번만 화면에 표시됩니다. Copy 버튼으로 복사한 뒤, 관리자 페이지 로그인 화면의 "Personal Access Token" 입력란에 붙여넣고 연결하기를 누릅니다.

이 화면을 나가면 토큰을 다시 볼 수 없으니, 붙여넣기 전에 다른 창을 닫지 마세요.

토큰이 만료되었을 때 나타나는 증상

게시하기를 눌렀을 때 "토큰이 만료되었거나 권한이 없습니다" 라는 메시지가 뜨면 토큰이 만료되었거나 저장소 접근 권한이 변경된 것입니다. 이 경우 위 1~4단계를 다시 진행해 새 토큰을 발급받은 뒤, 관리자 페이지의 설정 탭에서 토큰을 새로 입력하고 연결 테스트를 눌러 확인해주세요.

토큰 보관 시 주의사항

이 토큰은 비밀번호와 동일하게 취급해야 합니다. 캡처, 메신저, 이메일 등으로 다른 사람에게 전달하지 마세요. 토큰이 유출되었다고 의심되면 GitHub의 토큰 목록에서 즉시 Delete(삭제) 한 뒤 새로 발급받으세요. 관리자 페이지는 이 컴퓨터의 브라우저 저장소에만 토큰을 보관하며, 별도의 서버로 전송하지 않습니다.
